# Reanelcar - Proyecto Integrador de Estructuras de Datos

Este repositorio contiene las prácticas de la asignatura **Estructuras de Datos** (Universidad de Jaén). A lo largo del curso se desarrolla el sistema **Reanelcar**, un software para la gestión de una flota de vehículos eléctricos, usuarios, trayectos y puntos de recarga.

El proyecto evoluciona de manera incremental, aplicando estructuras de datos con complejidad temporal y espacial cada vez más eficiente:

* **PR1 - Vector Dinámico**: Memoria dinámica contigua y ordenación (`VDinamico`).
* **PR2 - Lista Doblemente Enlazada**: Punteros bidireccionales e iteradores (`ListaDEnlazada`).
* **PR3 - Árboles Balanceados**: Jerarquías y búsquedas balanceadas $O(\log n)$ (`AVL`).
* **PR4 - Contenedores STL**: Refactorización con la librería estándar C++ (`std::map`, `std::set`, `std::vector`).
* **PR5 - Tablas Hash**: Búsqueda $O(1)$ con dispersión y resolución de colisiones (`Hash`).
* **PR6 - Malla Espacial**: Indexación geográfica 2D mediante celdas UTM (`MallaRegular`).

> *Nota: Para consultar detalles de implementación, compilación o enunciados específicos, revisa el archivo `README.md` presente dentro de la carpeta de cada práctica.*
